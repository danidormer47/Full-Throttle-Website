# Full Throttle

Full Throttle is a motorsport ticket management website prototype designed to provide an accessible and organised experience for motorsport fans.

The website features events across Formula 1, MotoGP, NASCAR and Supercars, allowing users to explore events, interact with ticket booking interfaces and create event listings.

## Features

- Motorsport event listings and detailed event pages
- Ticket booking and management interfaces
- Event creation with browser-based data storage
- Login and registration interface prototypes
- Booking history interface
- Bootstrap-based user interface

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- GitHub

## Project Purpose

This project combines my interest in motorsport with software development, demonstrating my experience in front-end development, user interface design and interactive web applications.

## Running the Project

Download or clone the repository and open `index.html` in a web browser.

This project is a front-end prototype and does not process real payments or provide server-side authentication.
